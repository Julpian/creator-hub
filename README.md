## 📌 About Project

**Creator Hub** adalah platform Influencer Management yang dikembangkan untuk **Gen Creator Hub 2025**.  
Aplikasi ini membantu perusahaan digital mengelola creator, campaign, dan kolaborasi secara terintegrasi dalam satu sistem modern.

Dirancang sebagai aplikasi full-stack dengan fokus pada:

⚡ Performance  
🎯 Scalability  
🎨 Modern UI  
🔐 Secure API
